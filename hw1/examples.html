Famous Software Failures

1. Ariane 5 Rocket Explosion (1996)

  • Cause: Integer overflow error
  • Cost: ~$370 million
  • Lesson: Reused software must be carefully re-tested

The rocket self-destructed 37 seconds after launch.

2. Mars Climate Orbiter (1999)

  • Cause: Metric vs imperial unit mismatch
  • Result: Spacecraft destroyed
  • Lesson: Small mistakes can have huge consequences

3. Healthcare.gov Launch (2013)

  • Cause: Poor testing and system overload
  • Result: Website crashes
  • Lesson: Scalability and load testing are critical

4. Knight Capital Trading Bug (2012)

  • Cause: Old code accidentally activated
  • Loss: $440 million in 45 minutes
  • Lesson: Deployment and code management matter

Why These Failures Are Important

These cases show that:

  • Software failures affect real lives
  • Testing and validation are essential
  • Human decisions matter as much as code
